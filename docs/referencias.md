# Sobre os subjects

Os desafios deste repositório são textos originais, elaborados para fins de estudo e prática.

Cada subject define o problema, os limites e os comportamentos observáveis esperados. O objetivo é que qualquer pessoa possa tentar resolvê-lo sem depender de uma solução publicada e, depois, use a régua de avaliação para validar sua própria entrega.

## Referências

Alguns materiais públicos foram consultados como referência técnica para
componentes, temas e comportamentos esperados dos desafios:

- [Códigos de referência para projetos com Arduino](https://github.com/Strongreen/Kit_Maker_Arduino_FilipeFlop)
- [Playlist pública de vídeos sobre os projetos](https://www.youtube.com/playlist?list=PLqndzsAbM5fQJdS4PwY9wK9zxoqDA-CsJ)

Parte desses materiais faz referência à FilipeFlop, atualmente MakerHero.
Os links são mantidos para contextualizar a origem dos temas e facilitar
o acesso aos materiais públicos relacionados. Este repositório é uma
iniciativa independente.

## Ao contribuir

- escreva subjects, critérios e explicações com texto próprio;
- mantenha os desafios autocontidos;
- não inclua soluções completas no repositório;
- não copie código, imagens ou outros materiais de terceiros sem autorização ou licença compatível.
