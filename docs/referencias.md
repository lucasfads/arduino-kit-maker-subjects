# Sobre os subjects

Os desafios deste repositório são textos originais, elaborados para fins de estudo e prática.

Cada subject define o problema, os limites e os comportamentos observáveis esperados. O objetivo é que qualquer pessoa possa tentar resolvê-lo sem depender de uma solução publicada e, depois, use a régua de avaliação para validar sua própria entrega.

## Referências

Alguns materiais públicos foram consultados como referência técnica para componentes, temas e comportamentos esperados dos desafios:

- [Códigos de referência para projetos com Arduino](https://github.com/Strongreen/Kit_Maker_Arduino_FilipeFlop)
- [Playlist pública de vídeos sobre os projetos](https://www.youtube.com/playlist?list=PLqndzsAbM5fQJdS4PwY9wK9zxoqDA-CsJ)

Parte desses materiais faz referência à FilipeFlop, atualmente MakerHero. Os links são mantidos para contextualizar a origem dos temas e facilitar o acesso aos materiais públicos relacionados. Este repositório é uma iniciativa independente.

## Uso e adaptações

Você pode fazer um *fork* deste repositório e adaptá-lo à sua própria trilha de estudo. O projeto é disponibilizado como material educacional independente, sem compromisso de manutenção contínua ou análise de *pull requests*.

Ao adaptar os subjects, mantenha textos, critérios e explicações próprios e não inclua código, imagens ou outros materiais de terceiros sem autorização ou licença compatível.
